Sukari dashboard (Flask)

The app runs with Flask. From this folder, run:

pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000/

Deploy on Vercel

Push this project to GitHub, import it in the Vercel dashboard, accept the defaults (Vercel detects the Flask app in app.py). No build command is required. Ensure data.xlsx (or data/data.json) is committed so the dashboard can load.
